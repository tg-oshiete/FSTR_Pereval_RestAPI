SQLite используется только для быстрых проверок Python/HTTP. PostgreSQL-тесты
создают новый контейнер и отдельную БД для каждого теста; пользовательские
настройки не используются. Нет Docker — ошибка теста, а не успешный пропуск.
Сетевые проверки запускают отдельный Uvicorn и работают по TCP без overrides.

Команды: [README — проверки QA и CI](../Readme.md#проверки-qa-и-ci).
Дополнительная диагностика миграции старых фото/хранения:
`python scripts/check_postgres.py` — создаёт собственный PostgreSQL 18 и удаляет его.

## Секреты и история

Текущие файлы для Git проверяются Gitleaks, включая новые неигнорируемые файлы.
Перед сканированием проверяется работоспособность детектора на синтетических
секретах. Пользовательские `.env` не читаются и не передаются в Docker-образ.

Файлы `.env` и `app/.env` удалены из всей истории, вместе с прежними файлами IDE
и Python bytecode. Исключение `.gitleaksignore` удалено. Gitleaks проверяет текущие
файлы и все доступные коммиты без исключений для отдельных находок; комментарии
`gitleaks:allow` тоже не подавляют проверку. Результат — 0 находок.

История переписана, поэтому прежние хеши коммитов изменились. Старые клоны
нельзя объединять с очищенной веткой: используйте новую копию репозитория.
Удаление из Git не отзывает реквизиты и не удаляет чужие копии или кеш GitHub.
Локальные пользовательские `.env` не менялись и остаются вне контроля версий.
