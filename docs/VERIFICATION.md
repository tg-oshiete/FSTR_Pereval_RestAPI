## Матрица сценариев

| Область | Проверки |
| --- | --- |
| Контракт HTTP | POST/GET/PATCH/списки, 401/403/404/405/409/413/422/500, JSON/OpenAPI, безопасные ошибки |
| Частичное изменение | Каждый сезон, отдельная высота, пропуск/null, неизвестные поля, атомарное отклонение |
| Изображения | JPEG/PNG, строгий base64, повреждения/APNG, границы байтов/количества/геометрии, замена и очистка |
| Права | Свои/чужие ID, email и история; модератор не меняет содержимое; отзыв/TTL |
| PostgreSQL | FK/CHECK/UNIQUE/NOT NULL, старые данные, upgrade/downgrade, отдельные сессии |
| Транзакции | Сбои после INSERT и перед commit; прежние фото/данные; статус и история вместе |
| Гонки | Реальное ожидание блокировки через pg_blocking_pids, оба порядка edit/moderate, два конкурирующих решения |
| Демо | Защита режима, конкурентный seed без дублей, полный rollback, два сетевых показа, отзыв токенов при сбое |

SQLite используется только для быстрых проверок Python/HTTP. PostgreSQL-тесты
создают новый контейнер и отдельную БД для каждого теста; пользовательские
настройки не используются. Нет Docker — ошибка теста, а не успешный пропуск.
Сетевые проверки запускают отдельный Uvicorn и работают по TCP без overrides.

Команды: [README — проверки QA и CI](../Readme.md#проверки-qa-и-ci).
Дополнительная диагностика миграции старых фото/хранения:
`python scripts/check_postgres.py` — создаёт собственный PostgreSQL 18 и удаляет его.

## Секреты и история

Текущие файлы для Git проверяются Gitleaks, включая новые неигнорируемые файлы.
Перед сканированием проверяется работоспособность детектора на синтетических
секретах. Пользовательские `.env` не читаются и не передаются в Docker-образ.

В `.gitleaksignore` сохранён один точный отпечаток старого `app/.env` в коммите
`2e02e13`. Он не исключает новые коммиты или текущие файлы. Владелец ранее подтвердил,
что это неиспользовавшиеся учебные реквизиты. Историческое исключение не означает
ротацию или удаление старого значения из опубликованной истории. Значения
реквизитов в документации не приводятся.
