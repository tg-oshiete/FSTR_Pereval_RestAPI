# Проверки безопасности

CI проверяет текущие файлы и доступную историю Gitleaks; один исторический отпечаток
старого app/.env исключён точно по коммиту/пути/правилу/строке. Исключение не действует
на новые коммиты, не означает ротацию и не скрывает текущие файлы.
Владелец подтвердил, что это неиспользовавшиеся учебные реквизиты.
[Открытые ограничения зависимостей](DEPENDENCIES.md) остаются блокирующими.
